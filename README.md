# The poem about permission

A small Node program that writes one original short poem about agency — the power to ask and to be given — to `entry.txt`. An agent asks "may I?", is handed a key, and finds the asking itself was the gift.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the poem to `out/entry.txt` (251 Unicode characters, deterministic — every run produces the same bytes).
